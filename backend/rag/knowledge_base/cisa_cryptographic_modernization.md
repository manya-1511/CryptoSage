# CISA Guidance on Cryptographic Modernization

The Cybersecurity and Infrastructure Security Agency (CISA), in
coordination with NIST and NSA, has published guidance urging critical
infrastructure operators and device manufacturers to inventory
cryptographic algorithm usage and prioritize migration away from
deprecated primitives (DES, 3DES, RC4, MD5, SHA-1) toward NIST-approved
alternatives, as part of both routine security hygiene and broader
post-quantum cryptography transition planning.

CISA guidance emphasizes that embedded and firmware-based systems are
disproportionately likely to retain legacy cryptography long after it
has been deprecated elsewhere, because firmware updates are less
frequent than general-purpose software patching -- making proactive
firmware-level cryptographic algorithm identification (as opposed to
waiting for an incident) a recommended practice for device
manufacturers and operators of embedded/IoT/ICS fleets.
