# SHA-3 Standard

FIPS 202 specifies SHA-3, a family of hash functions based on the
Keccak sponge construction, selected by NIST in 2012 through a public
competition as a structurally independent alternative to SHA-2. SHA-3
is not a replacement mandated by a weakness in SHA-2; rather, it
provides algorithmic diversity, so that a future cryptanalytic
breakthrough against the SHA-2 family's Merkle-Damgard structure would
not simultaneously compromise SHA-3.

SHA-3 is approved by NIST for the same use cases as SHA-2 (digital
signatures, integrity verification, HMAC construction) and offers
SHA3-224/256/384/512 fixed-output variants as well as the extendable-
output functions SHAKE128 and SHAKE256.
